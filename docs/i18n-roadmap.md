## 简体中文

P0 规则：主要教程和推广材料必须中英双语。

当前优先级：

1. README：中英双语。
2. Start Here：中英双语。
3. Lessons：每课中英双语。
4. Public release material：中英双语。
5. Templates：至少标题、说明和验收标准中英双语。

后续热门语言可以用 AI 直接翻译，但必须保留人工抽查：

- Japanese
- Korean
- Spanish
- Portuguese
- French
- German
- Hindi

质量规则：

- 不允许机器翻译破坏命令、文件名、时间码、SRT 格式。
- 技术术语保留英文原词时，要给一句解释。
- 每次新增语言都要先覆盖 README 和 Lesson 01。

<a id="english"></a>

## English

P0 rule: core tutorials and promotion materials must be bilingual in Chinese and English.

Future high-traffic languages may be AI-translated, with human review:

- Japanese
- Korean
- Spanish
- Portuguese
- French
- German
- Hindi

Do not let translation alter commands, filenames, timestamps, SRT format, or HyperFrames attributes.
