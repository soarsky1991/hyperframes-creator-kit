# i18n Roadmap

语言：[简体中文](i18n-roadmap.md) · [English](i18n-roadmap.en.md)

P0 规则：主要教程和推广材料必须提供独立中文页和英文页，通过顶部链接互相切换。

当前优先级：

1. README：`README.md` 中文页 + `README.en.md` 英文页。
2. Start Here：`START_HERE.zh-CN.md` + `START_HERE.en.md`。
3. Lessons：每课 `README.md` 中文页 + `README.en.md` 英文页。
4. Public release material：中文页和英文页分开维护。
5. Templates：至少标题、说明和验收标准提供独立英文页。

后续热门语言可以用 AI 直接翻译，但必须保留人工抽查：

- Japanese
- Korean
- Spanish
- Portuguese
- French
- German
- Hindi

质量规则：

- 不允许机器翻译破坏命令、文件名、时间码、SRT 格式。
- 技术术语保留英文原词时，要给一句解释。
- 每次新增语言都要先覆盖 README 和 Lesson 01。
- 不把两种语言堆在同一个页面里。
