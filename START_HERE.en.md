# Start Here: Build Your First Credible Tutorial Video in 10 Minutes

Languages: [Chinese](START_HERE.zh-CN.md) · [English](START_HERE.en.md)

Goal: do not start from "make a flashy AI video." Start from "prove one real workflow."

## What You Need

- A 10-30 second real screen recording: terminal, browser, design tool, or HyperFrames preview.
- One clear teaching promise: what can the learner reproduce?
- One final handoff: video, SRT, cover, publish copy, and risk review.

## The 10-Minute Flow

1. Write one promise:

   ```text
   After watching this, you can turn a real screen recording into a 30-second HyperFrames tutorial video.
   ```

2. Sort assets into three buckets:

   | Type | Job | Examples |
   |---|---|---|
   | proof | Prove the workflow happened | Screen recording, terminal output, preview screenshot |
   | teaching | Help viewers understand | Step cards, parameter cards, error explanation |
   | polish | Improve watchability | BGM, SFX, transitions, highlights |

3. Build the first version:

   - 0-3s: show the result.
   - 3-12s: show real workflow evidence.
   - 12-24s: explain with step cards.
   - 24-30s: show the output and next action.

4. Run the quality self-check:

   - Can viewers see the result in 3 seconds?
   - Does every teaching claim have proof?
   - Can subtitles stand alone without audio?
   - Does motion explain instead of hiding information?
   - Does the publish pack include title, cover, SRT, and risk review?
