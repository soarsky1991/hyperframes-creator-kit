## 简体中文

这是一个最小可运行 HyperFrames demo，用来证明仓库不是纯文档。

它使用图形化 proof panels 代替真实录屏。正式公开视频 MVP 必须替换成公开安全的真实录屏素材。

```bash
cd examples/lesson-01-proof-driven-30s-video
npm run check
npm run render
```

## English

This is a minimal runnable HyperFrames demo. It uses graphic proof panels as placeholders. The public video MVP must replace them with real public-safe screen recordings.

```bash
cd examples/lesson-01-proof-driven-30s-video

```
