# Lesson 05: 发布包、封面和风险审稿

语言：[简体中文](README.md) · [English](README.en.md)

目标：把一个 HyperFrames 教程视频变成可以人工发布的 package。

## 你会做出什么

- 标题候选。
- 封面方向。
- 正文文案。
- 评论区补充。
- SRT/字幕文件清单。
- 风险审稿。

## 发布包结构

```text
publish-pack/
  title.md
  cover.md
  body.md
  comments.md
  subtitles/
  risk-review.md
```

## 标题模板

- `我用 HyperFrames 把真实录屏做成 30 秒教程视频`
- `AI 教程视频别只做炫酷动效，先做 proof asset`
- `从一次失败 render 到可发布教程：HyperFrames 工作流复盘`

## 风险审稿

检查：

- 是否有密钥、账号、二维码、通知、支付页。
- 是否有未授权素材。
- 是否夸大承诺。
- 是否需要 AI 生成标注。
- 是否有不合适的外部跳转、重复宣传或平台不友好表达。

## 为什么重要

发布包让 repo 从“教程仓库”变成“创作者工作台”。这比单纯代码示例更容易被内容创作者收藏。
