## 简体中文

本项目采用轻量委员会治理，目标是防止仓库变成一次性 README。

## 核心委员会

| Role | Responsibility |
|---|---|
| Project Chair | 路线图、范围、优先级 |
| Technical Lead | HyperFrames 模板、skill、CI |
| Curriculum Editor | 课程路径、练习、案例质量 |
| Chinese Docs Lead | 中文 canonical、术语、风格 |
| i18n Lead | 英文镜像与后续多语质量 |
| DX/CI Lead | GitHub Actions、Pages、smoke checks |
| Growth Lead | X/知乎/掘金/B 站/Reddit 传播 |

## 决策规则

- 小修小补：48 小时 lazy consensus。
- 新 lesson / 新模板：至少 2 名 maintainer review。
- 目录大改、许可变更、官方 upstream：走 RFC。
- 商业合作或品牌联动：Project Chair + Growth Lead + Technical Lead 共同批准。

<a id="english"></a>

## English

This project uses lightweight committee governance so it does not become a one-off README dump.

Small fixes use 48-hour lazy consensus. New lessons and templates need two maintainer reviews. Major structure, license, or upstream changes need an RFC.
