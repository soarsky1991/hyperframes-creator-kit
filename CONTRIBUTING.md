# Contributing

This repo grows best through small, concrete teaching cases.

## Good first contributions

- Add one real tutorial case.
- Add one platform publishing checklist.
- Add one subtitle or motion-card pattern.
- Report one HyperFrames check/render failure with a minimal reproduction.
- Translate one lesson section.

## Contribution standard

A case is useful only when it includes:

- Learner promise.
- Required proof asset.
- Step sequence.
- Validation checklist.
- Final publish package.
- Integrity notes: AI labeling, copyright, privacy, platform risk.

## What not to add

- Decorative AI video with no proof asset.
- Huge lists of links without teaching flow.
- Claims like "production ready" without checks or examples.
- Private account screenshots, keys, QR codes, or paid-account details.
