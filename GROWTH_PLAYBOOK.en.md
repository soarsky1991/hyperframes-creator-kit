# Viral Tutorial Repo Growth Playbook

Languages: [简体中文](GROWTH_PLAYBOOK.zh-CN.md) · [English](GROWTH_PLAYBOOK.en.md)

Research date: 2026-06-01

The pattern behind high-star tutorial repositories is simple: the first screen earns the star, the first lesson earns trust, and the case library brings people back.

## Why 50k+ Star Tutorial Repos Spread

### 1. The name is the search query

Strong repo names answer a user job:

- `build-your-own-x`: I want to build a real thing from scratch.
- `developer-roadmap`: I do not know what to learn next.
- `system-design-primer`: I need to prepare for system design.
- `coding-interview-university`: I need a serious study plan.
- `generative-ai-for-beginners`: I am new but need to start building.

For this repo, the larger promise is:

```text
Build your own AI video workflow from real proof assets.
```

### 2. They reduce expensive anxiety

This repo should target one anxiety:

> I want to make AI tutorial videos, but I do not want fake-looking, unverifiable, decorative output.

### 3. The README is saveable before it is runnable

Many stars happen before usage. The README needs:

- One-line promise.
- Demo or screenshot.
- 10-minute quick start.
- Lesson map.
- Templates.
- Contribution path.

### 4. There is a first success moment

The first success moment here is:

```text
real screen recording -> 30-second tutorial video -> checks -> publish pack
```

### 5. Contribution is broken into small pieces

Good first contributions:

- Add one proof-asset checklist.
- Add one failure case.
- Add one lesson screenshot.
- Add one SRT example.
- Translate one section.

## Fast Traffic Plan

### Chinese channels

- Bilibili: publish the finished 30-60s demo, then a 3-5 minute breakdown.
- Xiaohongshu: publish the before/after image, workflow checklist, and repo link handoff.
- Zhihu/Juejin: write the proof-first argument and embed the demo.

### English channels

- X: before/after clip plus short thread.
- GitHub: keep README visual and issue templates active.
- Hacker News/Reddit: wait until the first runnable demo is stable.

## Risk

Do not market this as production ready yet. Market it as a public training seed with a strong first workflow and a transparent roadmap.
